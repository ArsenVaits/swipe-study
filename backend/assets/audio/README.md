# Music and sound effects for HyperFrames videos

Optional. Put licensed files here (mp3, wav, m4a, aac, ogg):

- `music/` — background beds. One is picked per video and played under the voice at volume 0.14.
- `sfx/` — short hits named by what they are, e.g. `whoosh-1.mp3`, `whoosh-2.mp3`, `pop-1.mp3`, `click-1.mp3`.
  Opus places them only on visible actions (whoosh on a transition, pop on a number landing). Max 12 files.

With both folders empty, videos have only the voice (or are silent with `TTS_PROVIDER=none`).
Only add files you have the rights to use.
