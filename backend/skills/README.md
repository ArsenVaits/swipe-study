# Skills used by the HyperFrames video pipeline

Original skill files, kept with their licenses. The backend prompt (`src/video/hyperframes/prompt.ts`) condenses
their rules for a single-file vertical explainer; the GSAP plugin sections are quoted verbatim at runtime
(`src/video/hyperframes/kit.ts`).
